Java ME GCF diagnostic

The emulator build also packages a MIDlet that exercises the actual javax.microedition.io Connector API. Get the GCF network probe MIDlet and run it in the emulator. The project build overlays HTTP(S), TCP and UDP GCF adapters on the pinned upstream source. Use the MIDlet to exercise those APIs; the browser/Tailscale path remains experimental until verified.

What this browser test can and cannot tell you

  • It tests a browser fetch request initiated by this page.
  • A CORS error means the browser did not expose the response to this page; it does not prove the remote server is offline.
  • It does not test Java blocking stream semantics, MIDP GCF, TCP sockets, UDP datagrams, or CheerpJ networking.
  • Do not enter private credentials, auth keys, or sensitive URLs.
